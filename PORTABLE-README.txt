AutoReview 1.4.2 自包含运行版 Windows x64
冻结日期：2026年10月16日

桌面便携版完整解压后运行 AutoReview.exe；保留 runtime 与 docs 文件夹。
独立浏览器运行包则运行 AutoReview-Service.exe，不要只复制单个EXE。
无需安装Python、Node、Rust或Codex桌面程序；官方CLI和本地图片方向模型已包含。
桌面版需要Microsoft Edge WebView2，缺少时运行便携包内的离线安装组件；安装版自动检测。

首次使用按官方流程登录ChatGPT，设置资料库、导出位置和班级。
使用顺序：确认教师范本和分值 → 导入或相机采集 → 检查图片 → 提交识别 → 教师复核 → 统计导出。
连续拍摄支持逐张云端识别，或仅本地保存后统一批量提交；批处理与流式并发度独立，默认各10。
Enter拍摄及检查确认，Esc停止采集；默认2秒准备下一张，可在设置中调整。
明确判定正确、错误或漏答后，书写状态同步结束待核实；支持撤销和重做。
单页失败不阻断其他页，同类错误连续3次终止本轮，检查后可确认继续缺失阶段。

资料默认位于Windows文档/AutoReview/Library，与程序和账户配置分离。
使用软件内资料库备份/迁移功能搬运资料，不要在应用运行时直接移动资料库，也不要复制账户令牌。
退出会停止本程序的后台工作，已保存数据保留。不要通过旧的本地网址代替启动程序。

完整说明：docs/USER_GUIDE.docx 或 docs/USER_GUIDE.md。
真实模型和硬件实测边界见项目对应报告；程序包不包含学生照片、测试数据、账户配置或凭据。

每个程序副本独立保存账户，首次为空白，Windows加密保存后可自动复用。
私有目录 .autoreview-private 不得分享；分发请使用原始ZIP。
删除便携目录前先在账户面板清除全部账户并退出；直接删目录无法触发系统凭据清理。
安装版卸载会清理本副本账户，作业资料库保留。
